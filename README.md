# Extrator de Fichas – Cadastro ALES
 
**Acesse:** https://gustavosarti.github.io/extrator-fichas-cadastro-ales/
 
## Como usar
1. Abra o link acima (Chrome ou Edge).
2. Preencha a **senha padrão** uma vez (fica salva só no seu navegador).
3. Arraste o PDF da ficha (pode ter várias fichas no mesmo PDF).
4. Clique em **Copiar** na linha que quiser e cole na plataforma.
## Privacidade
O PDF é lido no próprio navegador de quem usa. Nenhum dado é enviado para servidor, e a senha padrão não fica no código.
